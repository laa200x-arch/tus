# 职场那些事 Windows 桌面版

纯公益技能互换平台 Windows 客户端，与 iOS 版**功能一致、共用同一服务器**（任何设备数据实时同步）。

## 快速开始

```bash
cd win-app
npm install          # 安装依赖（Electron + socket.io + Leaflet）
npm start            # 启动应用（需要显示器）
```

> 若启动即闪退，先检查系统环境变量是否存在 `ELECTRON_RUN_AS_NODE=1`（会导致 Electron 以纯 Node 模式运行而无法加载界面）：
> ```bash
> set ELECTRON_RUN_AS_NODE=
> npm start
> ```
> 或直接双击 `start.bat`（已内置清除逻辑）。

## 打包与安装

```bash
npm run pack         # 便携版 exe（dist/）
npm run dist         # 安装版 exe（dist/职场那些事 Setup x.x.x.exe，可安装到开始菜单/桌面）
```

国内网络建议设置镜像加速：
```bash
$env:ELECTRON_MIRROR = 'https://npmmirror.com/mirrors/electron/'
$env:ELECTRON_BUILDER_BINARIES_MIRROR = 'https://npmmirror.com/mirrors/electron-builder-binaries/'
```

**绿色版**：`dist/win-unpacked/职场那些事.exe` 可直接双击运行（免安装）。

## 窗口与退出

- **桌面三栏布局**：左侧导航栏（技能匹配/互换动态/消息/宠物/我的 + 技能曝光推广卡）+ 顶部栏（消息铃铛 + 头像/用户名下拉菜单）+ 内容区
- **主题**：紫罗兰主色 + 暖橙强调 + 浅紫灰背景，现代卡片/胶囊风（与 iOS 端一致）
- **窗口可缩放**（最小 900×640），顶部栏可拖动
- **退出确认**：点击关闭按钮会弹出确认框（退出应用 / 最小化到托盘 / 取消）
- **最小化到托盘**：缩小后驻留系统托盘，继续接收消息与桌面通知；托盘菜单可「打开职场那些事」或「退出应用」

## 与 iOS 版的差异说明

| 能力 | iOS | Windows |
|---|---|---|
| 地图 | MapKit（区级示意） | Leaflet + OpenStreetMap（区级示意） |
| 拍照 | 系统相机 + 确认 | getUserMedia 摄像头 + 确认 |
| 语音 | AAC m4a | WebM（浏览器录音） |
| 通知 | 本地通知 | 系统桌面通知 |
| 实时通道 | Socket.io | Socket.io（同一服务端） |

所有数据（账号/聊天/吐槽/同事档案/公司属性）存储于同一服务器（http://43.157.17.88:8020），**iOS 与 Windows 完全互联互通**。
